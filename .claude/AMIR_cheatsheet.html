2 · Batch CLI: amir-batch

Runs PdfEngine over one or more PDFs (or every *.pdf in a directory) and prints a rich summary table.

Most useful invocations

# Process every PDF under samples/ → samples/out/<stem>/...
uv run amir-batch samples/

# Custom output root
uv run amir-batch samples/ -o samples/out

# Specific PDFs
uv run amir-batch samples/test-case-report1.pdf samples/test-pdf-ai-manuscript.pdf

# Skip the HTML preview (faster, no preview.html)
uv run amir-batch samples/ --no-preview

# Full standard-vs-full-page-VLM A/B per PDF (heavy: pulls GraniteDocling)
uv run amir-batch samples/ --compare

# Add Qwen2.5-VL-3B picture captions (heavy: vLLM + model download)
uv run amir-batch samples/ --picture-description qwen25_vl_3b

# Swap TableFormer for Granite-Vision VLM tables (heavy: 2B model)
uv run amir-batch samples/ --granite-vision-tables

# All flags
uv run amir-batch --help

Flag reference

FlagDefaultWhat it does
-o / --output-dirsamples/outRoot output directory. One subfolder per PDF.
-c / --compareoffRun run_comparison(): standard pipeline + full-page VLM, plus a comparison.md.
--vlm-presetgranite_doclingFull-page VLM preset for compare mode. DocTags-emitting presets keep the comparison apples-to-apples.
--preview / --no-preview--previewRender preview.html (clickable bbox viewer).
--images-scale1.5Render scale for page / picture / table crops.
--granite-vision-tablesoffSwap TableFormer for Granite-Vision VLM table structure. Opt-in (downloads a 2B model).
--picture-descriptionoffPer-figure VLM captions. Values: off · smolvlm · granite_vision · pixtral · qwen25_vl_3b.

3 · Use as a Python library

Single PDF

from pathlib import Path
from docling.engines import PdfEngine

out = PdfEngine(images_scale=1.5).convert(
    Path("samples/my-paper.pdf"),
    output_dir=Path("samples/out"),
    make_html_preview=True,
)
print(out.status, out.output_dir)
# samples/out/my-paper/{
#   my-paper.md, my-paper.embedded.md,
#   document.json, nodes.jsonl, chunks.jsonl,
#   tables.jsonl, figures.jsonl, run.json,
#   images/, preview.html
# }

Full-page VLM A/B comparison

from pathlib import Path
from docling.engines import run_comparison

res = run_comparison(
    Path("samples/my-paper.pdf"),
    Path("samples/out"),
    vlm_preset="granite_docling",  # default
)
# samples/out/my-paper/{
#   standard/, full_page_vlm/, comparison.md
# }

Common PdfEngine overrides

PdfEngine(
    save_artifacts=True,          # default — writes everything
    link_images=True,             # default — .md uses ![](images/...) refs
    embed_images=True,            # default — also writes <stem>.embedded.md (base64)
    filter_noise_pictures=True,   # default — strip logos/banners from .md, tag in figures.jsonl
    chunk_tokenizer="sentence-transformers/all-MiniLM-L6-v2",
    chunk_max_tokens=512,
    granite_vision_tables=False,  # opt-in: VLM-based tables (~2B model)
    picture_description=None,     # "smolvlm" | "granite_vision" | "pixtral" | "qwen25_vl_3b"
    picture_description_engine="vllm",
    images_scale=1.5,
)

4 · Output bundle (per PDF)

FileWhat
<stem>.mdPrimary markdown. Picture placeholders rewritten to ![](images/picture_NNN.png); noise pictures replaced by <!-- noise picture: ... -->.
<stem>.embedded.mdStandalone — base64-inlined images (same noise filtering). ~10–15× larger.
document.jsonFull DoclingDocument serialisation (round-trippable).
nodes.jsonlOne JSON per iterate_items() node: label, prov/bbox, text, captions, table data.
chunks.jsonlHybridChunker output: {index, text, token_count, headings, page_nos, self_refs}. RAG-ready.
tables.jsonlOne row per table: caption_text, markdown, html, dims, flat cells (with offsets and spans), image_path.
figures.jsonlOne row per figure: caption_text, image_path, vlm_caption, classifier_label, is_noise + noise_reason, annotations.
run.jsonReproducibility: schema_version, source, status, timing, engine_config, full pipeline_options, models summary, python/platform/package versions.
images/page_NNNN.pngPage renders.
images/picture_NNN.pngFigure crops (via PictureItem.get_image()).
images/table_NNN.pngTable crops (via TableItem.get_image()).
preview.htmlClickable bbox viewer. Summary chips at top; per-kind side panel on click (picture: caption + VLM desc + classifier + thumbnail; table: dims + rendered HTML; text: body). Noise pictures shown dashed-gray with badge.

In --compare mode each PDF gets an extra standard/ and full_page_vlm/ subfolder plus comparison.md.

6 · Inspecting outputs (jq one-liners)

# How many chunks and what's the longest one?
jq -s 'length, (map(.token_count) | max)' samples/out/my-paper/chunks.jsonl

# Section hierarchy of all chunks
jq -r '.headings | join(" / ")' samples/out/my-paper/chunks.jsonl | sort -u

# Tables: dims + caption
jq -r '[.index, .num_rows, .num_cols, .caption_text] | @tsv' samples/out/my-paper/tables.jsonl

# Figures: which ones are noise + why
jq -r 'select(.is_noise) | [.index, .classifier_label, .noise_reason] | @tsv' samples/out/my-paper/figures.jsonl

# run.json highlights
jq '.timing.duration_seconds, .models.layout.model_spec.name, .output_summary' samples/out/my-paper/run.json

8 · Tell Claude later

  • "run amir-batch on samples/" → executes uv run amir-batch samples/
  • "run the full-page VLM comparison on samples/foo.pdf" → calls run_comparison(...)
  • "refresh the preview for samples/test-pdf-ai-manuscript.pdf" → re-renders preview.html
  • "swap to Qwen3-VL" → changes repo_id in vlm_specs.py
